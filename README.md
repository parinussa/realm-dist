# realm-dist

Public distribution for **realm** — installers, release artifacts, and user docs.
Source lives in a private repo; this repo is published by CI on each tagged release.

## Install the control plane (Ubuntu/Debian)
```
curl -fsSL https://raw.githubusercontent.com/parinussa/realm-dist/main/install.sh | sudo bash
```

## Install the CLI (macOS/Linux)
```
curl -fsSL https://raw.githubusercontent.com/parinussa/realm-dist/main/install-cli.sh | bash
```
